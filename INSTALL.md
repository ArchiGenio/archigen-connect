# Install ArchiGen Connect

1. Download the latest installer from the [0.1.0-beta.1 GitHub Release](https://github.com/ArchiGenio/archigen-connect/releases/tag/v0.1.0-beta.1).
2. Run `ArchiGenConnectSetup-0.1.0-beta.1.exe`.
3. Complete the ArchiGen Connect setup flow.
4. Launch ArchiGen Connect.
5. Follow the **System Check / Preparation** flow.
6. Select your project folder when prompted.
7. Connect or repair Rhino MCP if setup requests it.
8. Open Rhino and Grasshopper.
9. Open the supported AI client workflow, such as the Copilot-compatible workflow.

Keep Rhino and Revit closed while setup performs installation or repair actions. If the system check reports a missing optional application, follow the prompt and consult [Requirements](REQUIREMENTS.md).

For problems during Beta setup, see [Troubleshooting](TROUBLESHOOTING.md).
