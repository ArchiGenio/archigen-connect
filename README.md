# ArchiGen Connect

## AI Agent for AEC

ArchiGen Connect connects compatible AI assistants with AEC design applications, helping you work with Rhino, Grasshopper, Revit workflows, and project context from one local setup.

**Beta**

**Current version: 0.1.0-beta.2**

```text
AI Assistant -> ArchiGen Connect -> Rhino / Grasshopper / AEC workflows
```

### Beta capabilities

- AI-assisted Grasshopper workflows
- Rhino connectivity
- Grasshopper definition inspection and modification
- Parametric workflow assistance
- Project-aware workflows
- Copilot-compatible workflow
- Foundation for Rhino.Inside.Revit and Revit workflows
